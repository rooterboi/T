# Husnixat shriftlari

Bu papkaga TTF fayllarni joylang (Google Fonts, bepul, OFL litsenziya). `services/handwriting.py` dagi `STYLES`
ro'yxatida qaysi fayl nomi kutilishi yozilgan:

| Fayl | Shrift |
|---|---|
| BadScript-Regular.ttf | Bad Script (kirill + lotin) |
| MarckScript-Regular.ttf | Marck Script |
| Caveat-Regular.ttf, Caveat-Bold.ttf | Caveat |
| Kalam-Regular.ttf, Kalam-Light.ttf | Kalam |
| Neucha-Regular.ttf | Neucha |
| Pangolin-Regular.ttf | Pangolin |
| AmaticSC-Regular.ttf | Amatic SC |
| Underdog-Regular.ttf | Underdog |

Fayl topilmasa, bot DejaVu Sans ga o'tadi (ishlaydi, lekin qo'lyozmaga o'xshamaydi).
12 variantning har biriga alohida shrift berish uchun `STYLES` dagi `font=` maydonini o'zgartiring.
Shriftni qo'shgach `data/previews/` papkasini o'chiring — namunalar qayta yaratiladi.
Tavsiya: o'zbekcha `oʻ`, `gʻ` belgilari uchun shriftda ' (apostrof) bo'lishi kifoya — bot ʻ ʼ ni ' ga almashtiradi.
